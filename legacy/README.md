# Aghrin PishFactor — سامانه اختصاصی صدور پیش‌فاکتور شرکت آهن آگرین

سامانه عملیاتی و یکپارچه برای مدیریت مشتریان، کاتالوگ و قیمت‌گذاری کالاهای فولادی، صدور پیش‌فاکتور با شماره‌گذاری یکتا، تولید خروجی رسمی A4 / PDF فارسی، گزارش‌گیری فروش و کنترل دسترسی مبتنی بر نقش.

---

## معماری و فناوری‌ها

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Vite 6 (راست‌چین کامل RTL با فونت فارسی `Vazirmatn`)
- **Database & Auth**: Firebase Firestore (ذخیره‌سازی پایدار با زیرمجموعه‌های Snapshot برای اقلام پیش‌فاکتور و تاریخچه وضعیت) + Firebase Authentication (ورود امن Google و کنترل دسترسی RBAC)
- **Security**: قوانین سخت‌گیرانه `firestore.rules`، شماره‌گذاری اتمیک یکتا با Transaction، ثبت `audit_logs` و جلوگیری از تغییر پیش‌فاکتورهای نهایی توسط کاربران غیرمدیر.

---

## ماژول‌های پیاده‌سازی‌شده (فاز اول — MVP)

1. **ورود و احراز هویت با نقش‌های کاربری**: پشتیبانی از دو نقش `مدیر سیستم` و `کارمند فروش` با کنترل دسترسی در رابط کاربری و سمت سرور (Firestore Rules).
2. **داشبورد عملیاتی**: آمار تعداد کل و امروز پیش‌فاکتورها، وضعیت‌ها (در انتظار، تأییدشده، لغوشده، منقضی‌شده)، مجموع مبالغ، نمودار روند ماهانه و آخرین مشتریان.
3. **مدیریت مشتریان**: ثبت، ویرایش، جستجو با نام و شماره موبایل، مشاهده پرونده مشتری و حذف با کنترل وابستگی پیش‌فاکتورها.
4. **مدیریت کالا و دسته‌بندی**: تعریف کالا با کد، مشخصات فنی، سایز، ضخامت، طول، واحد و قیمت پایه؛ ذخیره Snapshot در ردیف پیش‌فاکتور جهت حفظ سوابق قبلی.
5. **صدور پیش‌فاکتور**: شماره‌گذاری یکتای خودکار (`AG-1001` به بعد)، افزودن کالا از کاتالوگ یا ردیف دلخواه، فرمول دقیق `مبلغ نهایی = جمع کالاها + هزینه حمل + مالیات - تخفیف`، نمایش مبلغ به حروف فارسی، ذخیره پیش‌نویس و ثبت نهایی.
6. **PDF رسمی A4**: خروجی چاپی راست‌چین با فونت فارسی، لوگو و مشخصات فروشنده/خریدار، جدول کالاها، مبلغ به حروف، شرایط پرداخت و تحویل، محل مهر و امضا و سلب مسئولیت.
7. **آرشیو و جستجو**: فیلتر تاریخ، وضعیت، صادرکننده، کپی پیش‌فاکتور و مشاهده تاریخچه تغییر وضعیت.
8. **تنظیمات شرکت و مدیریت کاربران**: ویرایش اطلاعات تماس، لوگو، اطلاعات مالیاتی و بانکی شرکت، مدیریت دسترسی همکاران و بررسی Audit Log.
9. **گزارش‌های فروش و بکاپ**: گزارش روزانه/ماهانه/مشتریان/کاربران با خروجی اکسل (CSV با BOM فارسی) و خروجی بکاپ کامل JSON.

## راهنمای نصب و اجرا

### ۱. اجرای محلی (توسعه)
```bash
npm install
npm run dev
```
برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۲. اجرای تست‌ها و ساخت نهایی
```bash
npm test
npm run lint
npm run build
```

### ۳. نصب روی VPS با Docker Compose
```bash
cp .env.example .env
docker compose up -d --build
```
سرویس روی پورت `3000` بالا می‌آید (می‌توانید Nginx با گواهی SSL را به‌عنوان Reverse Proxy مقابل پورت `3000` قرار دهید).

### ۴. دریافت فایل نصب ویندوز (`.exe`) از GitHub
این مخزن مجهز به **GitHub Actions** (`.github/workflows/build-windows-exe.yml`) است:
1. پس از Push کردن کد به شاخه `main` در گیت‌هاب، به تب **Actions** یا **Releases** در صفحه مخزن بروید.
2. پس از پایان ساخت خودکار (~۲ دقیقه)، فایل‌های زیر آماده دانلود هستند:
   - `Aghrin-PishFactor-Setup-1.0.0.exe` (نصاب کامل ویندوز با ساخت میانبر دسکتاپ)
   - `Aghrin-PishFactor-Portable-1.0.0.exe` (نسخه پرتابل بدون نیاز به نصب)

ایمیل مدیر اصلی (`agrin.sazan@gmail.com`) به‌صورت خودکار در قوانین امنیتی `firestore.rules` به‌عنوان **مدیر سیستم** مقداردهی اولیه شده است.

2. از بخش **کاربران و لاگ فعالیت** می‌توانید همکاران فروش خود را دعوت کرده و نقش هر کاربر را مدیریت نمایید.

## راهنمای بکاپ و بازیابی

- **تهیه بکاپ دستی فوری**: از بخش `تنظیمات شرکت` گزینه «دانلود فایل بکاپ JSON» را بزنید و فایل خروجی را خارج از سرور (فضای ابری یا سیستم محلی) نگهداری کنید.
- **بکاپ‌گیری خودکار Firestore**: برای محیط عملیاتی، فعال‌سازی زمان‌بندی Export خودکار Firestore به Google Cloud Storage در کنسول Firebase توصیه می‌شود.
