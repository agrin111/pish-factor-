# اجرای نسخه ویندوزی Aghrin PishFactor (کاملاً آفلاین)

نسخه ویندوزی یک برنامه دسکتاپ مستقل است: روی آیکون کلیک می‌کنید و برنامه باز می‌شود.
**پس از ساخت/نصب، برنامه به اینترنت نیاز ندارد.**

هیچ‌کدام از این موارد لازم نیست:

- نصب Node.js (روی سیستم کاربر نهایی)
- نصب PostgreSQL
- نصب Docker
- اجرای دستور در ترمینال
- اتصال به اینترنت

## چرا آفلاین است؟

| بخش | وضعیت |
| --- | --- |
| فونت فارسی | فایل‌های `Vazirmatn` داخل برنامه (`assets/fonts`، `public/fonts`) — بدون Google Fonts |
| سرور برنامه | Next.js داخلی روی `127.0.0.1` با پورت آزاد محلی |
| دیتابیس | PostgreSQL همراه برنامه، داده‌ها در پوشه کاربر |
| PDF و چاپ | تولید سمت سرور با فونت جاسازی‌شده |
| آیکون و لوگو | فایل‌های محلی |
| شبکه | در `desktop/main.cjs` فقط `127.0.0.1` مجاز است و هر درخواست بیرونی مسدود می‌شود |

## دو فایل خروجی

| فایل | توضیح |
| --- | --- |
| `AghrinPishFactor-Setup-1.0.0.exe` | نصب معمولی؛ میان‌بر روی دسکتاپ و منوی Start می‌سازد |
| `AghrinPishFactor-Portable-1.0.0.exe` | **بدون نصب**؛ هر جا کپی کنید با دوبار کلیک اجرا می‌شود. داده‌ها همچنان در `%APPDATA%` ذخیره می‌شوند |

هر دو فایل در پوشه `release/` ساخته می‌شوند.

## ساخت فایل exe

فایل `.exe` باید **روی ویندوز** ساخته شود، چون باینری‌های PostgreSQL و موتور Prisma
مخصوص ویندوز باید همراه بسته شوند.

### روش ۱: دوبار کلیک روی `desktop\build-windows.bat` (ساده‌ترین)

1. یک بار Node.js 22 را از [nodejs.org](https://nodejs.org) نصب کنید (فقط برای ساخت).
2. فایل `desktop\build-windows.bat` را دوبار کلیک کنید.
3. اسکریپت خودش وابستگی‌ها را نصب، برنامه را بیلد و هر دو فایل exe را می‌سازد و
   پوشه `release` را باز می‌کند.

> مرحله اول (نصب وابستگی‌ها) به اینترنت نیاز دارد. اگر پوشه `node_modules` از قبل
> وجود داشته باشد، ساخت کاملاً آفلاین انجام می‌شود.

### روش ۲: GitHub Actions (بدون نیاز به ویندوز)

1. کد را روی شاخه `main` در GitHub قرار دهید.
2. در مخزن: **Actions** → **Windows Installer** → **Run workflow**.
3. پس از پایان، از بخش **Artifacts** فایل `AghrinPishFactor-Setup` را دانلود کنید؛
   هر دو فایل exe داخل آن است.

### روش ۳: دستی در PowerShell

```powershell
npm ci
npm run build
npm run desktop:build
```

## نصب و اجرا

**نسخه پرتابل:** فایل `AghrinPishFactor-Portable-1.0.0.exe` را هر جا می‌خواهید بگذارید و
دوبار کلیک کنید. اولین اجرا کمی طول می‌کشد (ساخت دیتابیس و جدول‌ها).

**نسخه نصبی:**

1. `AghrinPishFactor-Setup-1.0.0.exe` را اجرا کنید.
2. مسیر نصب را انتخاب کنید (نصب برای کاربر جاری، بدون نیاز به دسترسی مدیر سیستم).
3. میان‌بر روی دسکتاپ و منوی Start ساخته می‌شود.
4. روی آیکون کلیک کنید؛ پنجره «در حال آماده‌سازی پایگاه داده…» و سپس صفحه ورود باز می‌شود.

## ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `Aghrin@1404`

**بلافاصله** از مسیر «کاربران و لاگ فعالیت» رمز را تغییر دهید.

سپس در «تنظیمات شرکت» لوگو، تلفن، نشانی، شناسه ملی و کد اقتصادی واقعی را وارد کنید؛
همین اطلاعات در سربرگ پیش‌فاکتور، PDF و «سربرگ متفرقه» استفاده می‌شود.

## محل نگهداری داده‌ها

```
%APPDATA%\Aghrin PishFactor\data\
  pgdata\        ← دیتابیس PostgreSQL
  config.json    ← کلید نشست و رمز داخلی دیتابیس (خودکار ساخته می‌شود)
  desktop.log    ← گزارش اجرا برای عیب‌یابی
```

برای پشتیبان‌گیری، از داخل برنامه «تنظیمات شرکت → دانلود نسخه پشتیبان JSON» را بزنید.
برای پشتیبان کامل، کافی است برنامه بسته باشد و پوشه `pgdata` کپی شود.

## انتقال برنامه به کامپیوتر دیگر (آفلاین)

1. نسخه پرتابل (`AghrinPishFactor-Portable-1.0.0.exe`) را با فلش کپی کنید.
2. برای انتقال داده‌ها، پوشه `%APPDATA%\Aghrin PishFactor` را هم کپی کنید.

## به‌روزرسانی خودکار از گیت‌هاب

برنامه نصب‌شده (`AghrinPishFactor-Setup-*.exe`) به‌طور خودکار در صورت دسترسی به اینترنت، نسخه‌های جدید را از بخش **Releases** مخزن گیت‌هاب بررسی و دریافت می‌کند:

- **برای کاربر نهایی:** پس از انتشار نسخه جدید روی گیت‌هاب، برنامه به‌صورت خودکار فایل آپدیت را در پس‌زمینه دریافت کرده و پیام «به‌روزرسانی جدید آماده است» را نمایش می‌دهد. همچنین در پایین منوی سمت راست گزینه **«بررسی به‌روزرسانی از گیت‌هاب»** وجود دارد. تمام پیش‌فاکتورها، مشتریان و تنظیمات هنگام آپدیت حفظ می‌شوند.
- **برای انتشار نسخه جدید (توسعه‌دهنده):** یک تگ نسخه جدید مثل `v1.0.1` روی گیت‌هاب بسازید (`git tag v1.0.1 && git push origin v1.0.1`) یا در تب **Actions → Windows Installer → Run workflow** گزینه انتشار Release را فعال کنید. گردش‌کار به‌صورت خودکار `Setup.exe`، `latest.yml` و `.blockmap` را در **GitHub Releases** منتشر می‌کند.

## حذف برنامه

حذف از «Programs and Features» فقط برنامه را برمی‌دارد؛ داده‌ها در `%APPDATA%` باقی
می‌مانند. برای حذف کامل، پس از حذف برنامه پوشه
`%APPDATA%\Aghrin PishFactor` را پاک کنید.

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| پنجره باز نمی‌شود | فایل `%APPDATA%\Aghrin PishFactor\data\desktop.log` را بررسی کنید |
| خطای «سرور آماده نشد» | آنتی‌ویروس را برای پوشه نصب موقتاً غیرفعال کنید و دوباره اجرا کنید |
| اجرای هم‌زمان دو نسخه | برنامه تک‌نمونه‌ای است؛ نسخه دوم پنجره اول را فعال می‌کند |
| فراموشی رمز مدیر | با پشتیبان‌گیری از `pgdata`، از یک نسخه پشتیبان قبلی بازگردانی کنید |
| ساخت exe با خطای باینری PostgreSQL | `npm ci` را دوباره اجرا کنید تا `@embedded-postgres/windows-x64` نصب شود |
