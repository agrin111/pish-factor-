# نصب نسخه ویندوزی Aghrin PishFactor

نسخه ویندوزی یک برنامه دسکتاپ است: روی آیکون کلیک می‌کنید و برنامه باز می‌شود.
هیچ‌کدام از این موارد لازم نیست:

- نصب Node.js
- نصب PostgreSQL
- نصب Docker
- اجرای دستور در ترمینال
- اتصال دائمی به اینترنت (فقط برای چاپ/دانلود PDF مرورگر لازم نیست؛ همه چیز محلی است)

## داخل نصب‌کننده چیست؟

| بخش | توضیح |
| --- | --- |
| Electron | پنجره برنامه و آیکون دسکتاپ |
| سرور Next.js | همان برنامه وب، به‌صورت داخلی روی `127.0.0.1` |
| PostgreSQL همراه | دیتابیس محلی؛ در اولین اجرا ساخته می‌شود |
| اسکریپت‌های migration | جدول‌ها در اولین اجرا خودکار ساخته می‌شوند |
| حساب مدیر اولیه | `admin` با رمز `Aghrin@1404` (بعد از اولین ورود تغییر دهید) |

## ساخت نصب‌کننده

ساخت فایل `.exe` باید **روی ویندوز** انجام شود (باینری‌های PostgreSQL و موتور Prisma
مخصوص ویندوز باید همراه بسته شوند).

### روش ۱: GitHub Actions (ساده‌ترین)

1. کد را روی شاخه `main` در GitHub قرار دهید.
2. در مخزن، تب **Actions** → گردش‌کار **Windows Installer** → **Run workflow**.
3. پس از پایان، فایل `AghrinPishFactor-Setup-<version>.exe` را از بخش
   **Artifacts** دانلود کنید.

### روش ۲: ساخت روی ویندوز

پیش‌نیازِ ساخت (نه استفاده): Node.js 22 و دسترسی به npm.

```powershell
npm ci
npm run build
npm run desktop:build
```

خروجی در پوشه `release/` با نام `AghrinPishFactor-Setup-1.0.0.exe` ساخته می‌شود.

## نصب

1. فایل `AghrinPishFactor-Setup-1.0.0.exe` را اجرا کنید.
2. مسیر نصب را انتخاب کنید (نصب برای کاربر جاری، بدون نیاز به دسترسی مدیر سیستم).
3. میان‌بر روی دسکتاپ و منوی Start ساخته می‌شود.
4. روی آیکون کلیک کنید؛ پنجره «در حال آماده‌سازی پایگاه داده…» و سپس صفحه ورود باز می‌شود.

اولین اجرا کمی طول می‌کشد (ساخت دیتابیس و جدول‌ها). اجراهای بعدی سریع‌تر است.

## ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `Aghrin@1404`

**بلافاصله** از مسیر «کاربران و لاگ فعالیت» رمز را تغییر دهید. برای تغییر رمز مدیر
همین صفحه گزینه «تغییر رمز» را دارد.

سپس در «تنظیمات شرکت» لوگو، تلفن، نشانی، شناسه ملی و کد اقتصادی واقعی را وارد کنید؛
همین اطلاعات در سربرگ پیش‌فاکتور، PDF و «سربرگ متفرقه» استفاده می‌شود.

## محل نگهداری داده‌ها

همه داده‌ها در پوشه کاربر ذخیره می‌شود:

```
%APPDATA%\Aghrin PishFactor\data\
  pgdata\        ← دیتابیس PostgreSQL
  config.json    ← کلید نشست و رمز داخلی دیتابیس (خودکار ساخته می‌شود)
  desktop.log    ← گزارش اجرا برای عیب‌یابی
```

برای پشتیبان‌گیری، از داخل برنامه «تنظیمات شرکت → دانلود نسخه پشتیبان JSON» را بزنید.
برای پشتیبان کامل، کافی است برنامه بسته باشد و پوشه `pgdata` کپی شود.

## حذف برنامه

حذف از «Programs and Features» فقط برنامه را برمی‌دارد؛ داده‌ها در `%APPDATA%` باقی
می‌مانند. برای حذف کامل، پس از حذف برنامه پوشه
`%APPDATA%\Aghrin PishFactor` را پاک کنید.

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| پنجره باز نمی‌شود | فایل `%APPDATA%\Aghrin PishFactor\data\desktop.log` را بررسی کنید |
| خطای «سرور آماده نشد» | آنتی‌ویروس را برای پوشه نصب موقتاً غیرفعال کنید و دوباره اجرا کنید |
| اجرای هم‌زمان دو نسخه | برنامه تک‌نمونه‌ای است؛ نسخه دوم پنجره اول را فعال می‌کند |
| فراموشی رمز مدیر | با پشتیبان‌گیری از `pgdata`، از یک نسخه پشتیبان قبلی بازگردانی کنید |
